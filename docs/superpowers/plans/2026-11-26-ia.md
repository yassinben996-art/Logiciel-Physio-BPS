# Suggestions par IA et « Copier pour Claude » — plan d'implémentation 2b

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un bouton « Demander à l'IA » envoie au relais un résumé anonymisé et nettoyé du bilan (aperçu modifiable avant l'envoi). Le relais interroge Groq, puis un repli, puis OpenRouter, et renvoie jusqu'à 5 suggestions que Yass ajoute, note ou ignore. Un bouton « Copier pour Claude » copie le même résumé, précédé d'une consigne.

**Architecture:** Côté app, `src/bilan/ai/` contient des fonctions pures : résumé (`summary.ts`), nettoyage (`scrub.ts`) et lecture de la réponse (`response.ts`). Les consignes sont des fichiers de contenu (`src/bilan/content/aiPrompt.ts`). L'état des suggestions vit dans `BilanState.ai`. Côté relais, une route `POST /ai` (`relay/src/ai.ts`) appelle des fournisseurs compatibles OpenAI (Groq, OpenRouter) dans l'ordre d'une configuration, avec une limite horaire tenue en D1.

**Tech Stack:** l'existant (Vite, React, TypeScript, Vitest, Worker Cloudflare, D1). Aucune nouvelle dépendance.

**Spec:** `docs/superpowers/specs/2026-11-26-ia-design.md`

## Global Constraints

- Jamais envoyé à l'IA ni copié pour Claude : nom, prénom, date de naissance, code `B-…`, id du bilan, dates de création ou de modification.
- Textes libres nettoyés : `[nom]`, `[date]`, `[lieu]`, et `[téléphone]` / `[e-mail]`. Aperçu **modifiable** avant l'envoi ; les retouches ne modifient pas le bilan.
- Ordre de bascule par défaut : Groq `openai/gpt-oss-120b` → Groq `llama-3.3-70b-versatile` → OpenRouter `openai/gpt-oss-120b:free` → règles seules. On passe au suivant sur 429, 5xx, délai de 20 s ou réponse invalide. Un fournisseur sans clé est sauté.
- Au plus 5 suggestions ; types `hypothese`, `test`, `questionnaire`, `drapeau`.
- Libellés exacts : « Demander à l'IA », « Voici ce qui sera envoyé », « Envoyer », « L'IA réfléchit… », « Annuler », « IA · non sourcé », « Noter », « Ignorer », « Ajouter », « IA indisponible pour le moment, seules les règles sont actives », « L'IA a répondu de façon inattendue », « Copier pour Claude », « Hors connexion ».
- « Noter » ajoute à la fin de `raisonnement.notes` la ligne : `Suggestion IA (non sourcée) : <libellé> — <raison>`.
- Relais : 30 appels `/ai` par heure pour tout le compte, compteur en D1 ; aucune journalisation des requêtes ni des réponses. Secrets : `GROQ_API_KEY`, `OPENROUTER_API_KEY` (facultatif).
- Toutes les contraintes des plans précédents (chiffrement, aucun `localStorage`, rien de coché automatiquement, lint, typecheck et tests verts).

## Review Focus

1. **Le prénom ou le nom du patient tapé dans une note**, avec ou sans accents ni majuscules (« yassine », « BENSAÏD »), dans l'accueil (activités du PSFS) ou dans n'importe quelle section : remplacé par `[nom]` dans l'aperçu. → test dans la tâche 1.
2. **Noms de tests cliniques à majuscule** (« Neer », « Hawkins-Kennedy », « Jobe », « Lachman ») : pas pris pour des noms de personne. → test dans la tâche 1.
3. **L'IA renvoie du texte non JSON, du JSON tronqué, 12 suggestions ou un type inconnu** : rien ne plante ; on garde au plus 5 suggestions valides, sinon « L'IA a répondu de façon inattendue ». → test dans la tâche 2.
4. **Groq épuisé (429) puis OpenRouter en panne** : on obtient « IA indisponible… », les règles restent affichées, et l'outil reste utilisable. → tests dans les tâches 3 et 5.
5. **Nouvelle demande alors que des suggestions ont déjà été ajoutées, notées ou ignorées** : ce qui a été ajouté ou noté reste, et ce qui a été ignoré est envoyé comme « déjà écarté ». → test dans la tâche 4.

### Task 2: Consignes et lecture de la réponse de l'IA

**Files:**
- Create: `src/bilan/content/aiPrompt.ts`, `src/bilan/ai/response.ts`
- Test: `tests/bilan.ai.response.test.ts`

**Interfaces:**
- Produces :
  - `AI_SYSTEM_PROMPT: string` et `CLAUDE_PROMPT: string` dans `aiPrompt.ts`, contenu modifiable. Le premier rappelle : physiothérapie musculosquelettique ; pas de diagnostic médical ; pas de chiffre inventé ; réponse **uniquement** en JSON `{"suggestions":[{"type":"hypothese|test|questionnaire|drapeau","label":"…","reason":"…"}]}` ; au plus 5 ; ne pas reproposer « Déjà écarté » ; textes en français, raisons de moins de 160 caractères. Le second est une consigne pour un avis approfondi.
  - Dans `response.ts` :

```ts

export interface AiSuggestion { id: string; kind: AiKind; label: string; reason: string; target?: string /* "s.f" d'un test connu ou id de questionnaire */ }
export function parseAiResponse(text: string, z: ZoneDef, knownQuestionnaires: readonly { id: string; name: string }[]): AiSuggestion[]; // lève Error("L'IA a répondu de façon inattendue")
```
